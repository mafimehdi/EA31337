# اکسپرت طلای Patrick Nill (سبک PBD: Impulse → Range)

اکسپرت تمام‌اتوماتیک طلا (XAUUSD / GOLD) بر اساس استراتژی **Patrick Nill**:
**ایمپالس بزرگ ← سپس رنج (تراکم)** — معامله روی رنج، نه روی خود ایمپالس.

> توجه: فایل PDF ضمیمه شما در محیط من ذخیره نشد و قابل خواندن نبود،
> پس اکسپرت را بر اساس نسخه عمومی و مستند استراتژی Nill ساختم:
> مدل PBD، تایم‌فریم M15، فیلتر هفتگی Value Area (VAH/VAL)،
> دو سناریوی «پینگ‌پنگ داخل رنج» و «شکست + پولبک در جهت ایمپالس»،
> حد ضرر ATR، ریسک درصدی و مدیریت پوزیشن خودکار.
> اگر متن PDF را اینجا Paste کنید، دقیقاً با همان قوانین کالیبره‌اش می‌کنم.

## منطق استراتژی (خلاصه)

1. **تشخیص ایمپالس (P یا B):**
   - در تایم M15، حرکت خالص N کندل اخیر (پیش‌فرض ۲۰) باید بزرگ‌تر از `2.0 × ATR` باشد
   - حداقل ۶۰٪ کندل‌ها هم‌جهت باشند
2. **تشخیص رنج بعد از ایمپالس:**
   - N کندل آخر (پیش‌فرض ۱۵) فشرده باشند: اندازه رنج بین `0.25 تا 1.2 × ATR`
   - ساختار P: کف رنج بالای شروع ایمپالس صعودی باشد
   - ساختار B: سقف رنج پایین شروع ایمپالس نزولی باشد
3. **فیلتر Value Area هفتگی (تقریب Volume Profile):**
   - از دیتای H1 یک هفته اخیر، POC و محدوده ۷۰٪ حجم (VAH/VAL) محاسبه می‌شود
   - رنج باید با VAH / VAL / POC هم‌پوشانی یا تلاقی نزدیک (`0.5 × ATR`) داشته باشد
4. **ورودها (فقط با کندل بسته، فقط سرِ کندل جدید):**
   - **پینگ‌پنگ:** لمس لبه رنج + کندل ریجکشن (انگالف ساده) + تایید RSI
     - کف رنج + کندل صعودی → خرید به سمت سقف
     - سقف رنج + کندل نزولی → فروش به سمت کف
   - **شکست + پولبک:** کلوز قوی پشت لبه (در جهت ایمپالس) ← آرم شدن ← برگشت/ریتست لبه در N کندل بعد ← ورود ادامه‌دهنده
5. **خروج‌ها:**
   - حد ضرر = پشت لبه/سطح + بافر ATR
   - حد سود = حالت R:R (پیش‌فرض ۲R) یا لبه مقابل یا ATR
   - بریک‌ایون + تریلینگ ATR، خروج زمانی (پیش‌فرض ۷۲ ساعت)
6. **مدیریت ریسک:**
   - حجم از روی درصد ریسک بالانس + فاصله حد ضرر (TickValue/TickSize)
   - فیلتر اسپرد، فیلتر ساعت (۷ تا ۲۱ سرور)، گارد ضرر روزانه، بستن جمعه‌شب
   - فقط نماد طلا (XAU/GOLD) — روی بقیه نمادها معامله نمی‌کند

## نصب (MT5)

1. متاتریدر ۵ را باز کنید: `File → Open Data Folder`
2. فایل `XAU_PatrickNill_EA.mq5` را در `MQL5/Experts/` کپی کنید
3. `F4` (MetaEditor) → فایل را باز کنید → `F7` (Compile) — باید `0 errors` بدهد
4. به ترمینال برگردید، روی `XAUUSD,M15` درگ کنید
5. تیک‌ها را فعال کنید:
   - `Allow Algo Trading` (دکمه بالای ترمینال سبز باشد)
   - در پنجره اکسپرت: `Allow Automated Trading`
6. (اختیاری) `Load` کردن `XAU_M15_Default.set` در تب Inputs

## نصب (MT4)

1. `File → Open Data Folder` → کپی `XAU_PatrickNill_EA.mq4` در `MQL4/Experts/`
2. `F4` → باز کردن فایل → `F7` کامپایل (باید بدون خطا باشد)
3. روی چارت `XAUUSD,M15` بندازید + `AutoTrading` روشن + `Allow live trading`

## تنظیمات مهم (پیش‌فرض، قابل بهینه‌سازی)

- `InpSignalTF = M15` ،`InpValueAreaTF = H1`
- `InpImpulseBars = 20` ،`InpImpulseMinATR = 2.0` ،`InpRangeBars = 15`
- `InpRangeMaxATR = 1.2` ،`InpUseVAFilter = true`
- `InpRiskPercent = 1.0` (ریسک هر معامله ۱٪)
- `InpMaxSpreadPoints = 450` (بسته به بروکر تنظیم کنید؛ اگر معامله نمی‌کند اول اسپرد را چک کنید)
- `InpStartHour/EndHour = 7/21` (ساعت سرور؛ سشن لندن+نیویورک)

## تست قبل از حساب واقعی (خیلی مهم)

1. حتماً اول در **Strategy Tester** بک‌تست بگیرید: `XAUUSD, M15, Every tick based on real ticks`
2. بعد حداقل ۲-۴ هفته روی **دمو** فورواردتست
3. طلا نوسان شدید دارد — با `InpFixedLot` کوچک یا `InpRiskPercent=0.5` شروع کنید
4. اخبار مهم (NFP، CPI، FOMC) را یا فیلتر دستی کنید یا اکسپرت را خاموش کنید (خبرترید در این نسخه خودکار نیست)
