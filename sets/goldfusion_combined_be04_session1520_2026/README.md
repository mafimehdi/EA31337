# ترکیب دو تغییرِ هنوز آزمایش‌نشده

این بسته فقط دو فایل `.set` جدید دارد:

- `filter_001_be_04_session_15_20.set`: هر دو موتور، فقط بولینگر، BE در ۰٫۴ دلار، ساعت ورود ۱۵–۲۰ سرور.
- `filter_101_be_04_session_15_20.set`: هر دو موتور، UT + بولینگر، BE در ۰٫۴ دلار، ساعت ورود ۱۵–۲۰ سرور.

سایر ورودی‌ها دقیقاً مطابق `filter_001_center.set` و `filter_101_center.set` بستهٔ نزدیک قبلی باقی مانده‌اند، از جمله `TrailStartUSD=1.0` و `TrailDistUSD=1.0`. این دو تست برای دیدن **اثر ترکیب** BE=۰٫۴ و ساعت ۱۵–۲۰ هستند؛ سود دو آزمون تک‌عاملی را نباید با هم جمع زد.

در MT4 همان build 1481 اکسپرت، Alpari-Standard3، XAUUSD M15، ۵۰۰ دلار سپردهٔ تست، Every tick و **همان بازهٔ تست‌های اخیر: تاریخ انتخاب‌شدهٔ 2026-01-01 تا 2026-09-28** (گزارش‌ها: اولین کندل 2026-01-02 و آخرین 2026-09-25) را استفاده کنید. برای قیاس معتبر همان اسپرد گزارش‌های اخیر (`Current (36)`) را نگه دارید؛ اگر مقدار Current تغییر کرده، شش کنترل `filter_001_center.set`، `filter_101_center.set`، `filter_001_be_04.set`، `filter_101_be_04.set`، `filter_001_session_15_20.set` و `filter_101_session_15_20.set` را در همان شرایط جدید تکرار کنید. فایل SET تاریخ، اسپرد یا build را تعیین نمی‌کند.

این بسته فقط ورودی تست است، نه نتیجهٔ بک‌تست یا توصیه برای حساب واقعی؛ آزمون مستقل ۲۰۲۵ نامزدهای قبلی منفی بوده است.
