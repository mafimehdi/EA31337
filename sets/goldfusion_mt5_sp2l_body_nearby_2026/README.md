# آزمون حساسیت محلی نسبت بدنهٔ اسپایک در MT5

این بسته چهار INI مستقل MT5 دارد؛ سه حالت جدید و یک کنترل قبلاً تست‌شده. هر فایل `[Tester]` و تمام ۵۳ ورودی `[TesterInputs]` را طبق قالب ذخیره‌شدهٔ MT5 کاربر دارد. **تنها مقدار اصلی `SP2L_MinBodyRatio` تغییر می‌کند**؛ بخش‌های بهینه‌سازی پس از `||` همان نمونهٔ ذخیره‌شده باقی مانده‌اند و `Optimization=0` است.

- `goldfusion_mt5_sp2l_bodyratio_055.ini`: ۰٫۵۵
- `goldfusion_mt5_sp2l_bodyratio_060_control.ini`: ۰٫۶۰، کنترل قبلی: ‎$41.04+، PF1.43، افت Equity7.76%، ۳۰۹ معامله.
- `goldfusion_mt5_sp2l_bodyratio_065.ini`: ۰٫۶۵
- `goldfusion_mt5_sp2l_bodyratio_070.ini`: ۰٫۷۰

ثابت‌ها: `SignalMode=1` (فقط SP2L)، `ReversalPrimary=0`، `UseReversal=true`، `FixedLot=0.01`، `RiskUSD=10`، `RewardUSD=50`، `MaxOpenTrades=3`، `TradesPerSignal=3`، حساب MT5 Hedging، `XAUUSD_i` M15، سپردهٔ ۵۰۰ دلار، اهرم مؤثر 1:100، بازهٔ انتخابی 2026-01-01 تا 2026-09-28، real ticks. INI به فایل SET وابسته نیست. `Expert=15.ex5` مطابق نام EA تست‌شدهٔ کاربر است.

برای اجرا با `/config:` و بررسی اینکه مقادیر INI اعمال شده‌اند، از راهنمای بستهٔ قبلی استفاده کنید. اگر در رابط گرافیکی تست می‌کنید، **ورودی را دستی تغییر دهید**؛ دکمهٔ Load در تب Inputs ممکن است INI تستر را اعمال نکند. قبل از قبول هر گزارش، مقدار واقعی `SP2L_MinBodyRatio`، `SignalMode=1`، `UseReversal=true`، `ReversalPrimary=0` و اهرم 1:100 را در گزارش/Journal بررسی کنید. در صورت اهرم 1:1 هیچ معامله‌ای باز نمی‌شود و تست نامعتبر است. Results و خطوط `[EXIT_SUMMARY]` هر حالت جدید را بفرستید.

هدف این مرحله بررسی حساسیت نتیجه به مقادیر مجاور است، نه اثبات سودآوری آینده. انتخاب عدد از میان تست‌های مکرر روی همان سال ۲۰۲۶ خطر بیش‌برازش دارد؛ حتی اگر سود/افت یکی بهتر شود، بدون دادهٔ مستقل یا forward test تأیید حساب واقعی نیست. این فایل‌ها در MT5 توسط سازنده اجرا نشده‌اند.
