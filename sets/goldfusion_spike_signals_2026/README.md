# آزمون تک‌عاملی اسپایک SP2L — XAUUSD M15

این بسته یک کنترل و هشت تغییر تک‌عاملی نسبت به «تنظیم شخصی ۴» دارد. همهٔ فایل‌ها `MaxOpenTrades=3`، `TradesPerSignal=3`، `ATR_Period=14`، `RiskUSD=10`، `RewardUSD=50`، `BE_TriggerUSD=0.4` و ساعت سرور ۱۵–۲۰ دارند. فقط ورودی مشخص‌شده در هر فایل تغییر می‌کند؛ `manifest.csv` مقدار پایه و تغییر را ثبت می‌کند.

| هدف آزمایشی | نام کامل فایل | تغییر نسبت به کنترل |
|---|---|---|
| کنترل | `control_personal4_maxopen_3_persignal_3.set` | هیچ |
| سیگنال بالقوه بیشتر | `more_minspikeatr_0_9.set` | `SP2L_MinSpikeATR`: 1.2 → 0.9 |
| سیگنال بالقوه بیشتر | `more_minbodyratio_0_45.set` | `SP2L_MinBodyRatio`: 0.60 → 0.45 |
| سیگنال بالقوه بیشتر | `more_requiregap_false.set` | `SP2L_RequireGap`: true → false |
| سیگنال بالقوه بیشتر | `more_maxlegbars_16.set` | `SP2L_MaxLegBars`: 12 → 16 |
| سیگنال بالقوه کمتر | `fewer_minspikeatr_1_5.set` | `SP2L_MinSpikeATR`: 1.2 → 1.5 |
| سیگنال بالقوه کمتر | `fewer_minbodyratio_0_75.set` | `SP2L_MinBodyRatio`: 0.60 → 0.75 |
| سیگنال بالقوه کمتر | `fewer_strictbreak_true.set` | `SP2L_StrictBreak`: false → true |
| سیگنال بالقوه کمتر | `fewer_maxlegbars_8.set` | `SP2L_MaxLegBars`: 12 → 8 |

**شیوهٔ تست:** همهٔ فایل‌ها را با Alpari-Standard3، XAUUSD M15، ۵۰۰ دلار، Build 1481، Every tick، اسپرد ثابت ۴۷ و تاریخ انتخابی یکسان 2026-01-01 تا 2026-09-28 اجرا کنید. تاریخ پایان واقعی گزارش‌ها را کنترل کنید؛ قبلاً یک گزارش ۳/۳ زودتر از بقیه تمام شده بود. تاریخ و اسپرد در فایل SET نیستند. نتیجهٔ قبلی کنترل با داده تا ۲۵ سپتامبر +۸۱۶٫۷۸ دلار بود؛ در صورت تفاوت داده/شرایط، کنترل را دوباره اجرا کنید.

**محدودیت تفسیر:** نام `more`/`fewer` فرضیهٔ تغییر فراوانی سیگنال SP2L است، نه نتیجهٔ اثبات‌شده یا تضمین کیفیت. در `SignalMode=2`، Pullback برای ورود اولویت دارد؛ SP2L هم می‌تواند روی خروج معکوس اثر بگذارد. بنابراین شمار معاملات به‌تنهایی شمار سیگنال SP2L را نشان نمی‌دهد؛ سود، PF، افت سرمایه و جزئیات ورود و خروج را بررسی کنید. تغییر `SP2L_MaxLegBars` به‌خاطر انتخاب نزدیک‌ترین اسپایک می‌تواند اثر غیرخطی داشته باشد. `SP2L_SpikeBars=1` عمداً تست نشده: با الزام gap فعلی، حلقهٔ تشخیص gap برای یک کندل اجرا نمی‌شود و SP2L عملاً بی‌سیگنال می‌ماند. این فایل‌ها بک‌تست نشده‌اند؛ افزایش سود ۲۰۲۶ به‌تنهایی اثبات بهبود آینده نیست.
